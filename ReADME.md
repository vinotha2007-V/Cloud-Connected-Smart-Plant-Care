# 🌱 Cloud-Connected Smart Plant Care & Watering System

A cloud-connected smart plant monitoring and automated watering system that uses simulated IoT sensor data, a Node.js backend, React frontend, and Firebase cloud services.

The system monitors plant conditions such as soil moisture, temperature, and humidity, and provides a real-time dashboard for remote monitoring and plant care.

---

## 🚀 Features

- 🌱 Smart plant monitoring
- 💧 Soil moisture monitoring
- 🌡️ Temperature monitoring
- 💦 Humidity monitoring
- 🤖 Simulated IoT sensor data
- ☁️ Firebase Cloud Firestore integration
- 🔐 Firebase Authentication
- 📊 Real-time monitoring dashboard
- 💻 React-based frontend
- ⚙️ Node.js + Express backend
- 🔗 REST API
- 💾 Cloud database storage
- 📡 Remote plant monitoring
- 🚰 Automated watering logic
- 📈 Sensor data history
- 🛡️ Secure Firebase service integration
